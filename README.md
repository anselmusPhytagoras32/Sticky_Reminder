# Sticky_Remider: A Simple Python To-Do List

This is a basic task manager application built with **Python**. I created this project to learn how computer programs save files, organize data, and handle user instructions.

### What does it do?
Think of this as a digital notepad. You can:

* **Add new tasks** to your list.
* **View all your tasks** in one place.
* **Mark tasks as "Done"** when you finish them.
* **Delete tasks** you no longer need.
* **Auto-Save:** Your list is saved to a file automatically, so it remembers your tasks even if you turn off your computer.

###  How to Use
Once the program is running, you will see a simple menu on your screen like this:

1. **Add Task**
2. **Show Tasks**
3. **Mark Task as Done**
4. **Delete Task**
5. **Exit**
